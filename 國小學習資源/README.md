# 國小學生學習資源彙整

整理適合國小學生（一～六年級）使用的免費或公部門線上學習資源，依學科分類，方便家長、老師與學生快速查找。

> 網站內容與網址可能會變動，使用前請先確認；部分平台需以學校帳號或教育雲帳號登入。

---

## 線上測驗系統

[`quiz-app/`](quiz-app/) 是本資料夾附的國小線上測驗網站：國語、數學、英語、自然、社會、資訊六科，每科 1000 題，學生自行註冊，答對的題目不會再出現，並提供個人進度與全體登入進度統計報告（PostgreSQL）。
