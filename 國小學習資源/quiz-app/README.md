# 國小線上測驗系統

國小學生自行註冊、登入後練習六個科目，每科 **1000 題** 選擇題：

- **答對的題目不會再出現**；答錯的題目之後會再出現，直到答對為止。
- 每位學生有**自己的進度**（每科已答對題數、作答次數、正確率、需要加強的主題）。
- **使用者登入與進度統計報告**：管理者（老師）可看到全體學生的登入次數、登入天數、最後登入、作答與各科進度，可依年級篩選、下載 CSV、列印或存成 PDF。
- 資料庫使用 **PostgreSQL**。

| 科目 | 主題（每科 1000 題，平均分配） |
| --- | --- |
| 國語 | 相反詞、近義詞、詞語關係、量詞、部首、成語 |
| 數學 | 加減法、九九乘法、除法、多位數乘法、分數、小數、周長與面積、單位換算、因數倍數、百分率 |
| 英語 | 單字英翻中／中翻英、拼字、數字、星期與月份、名詞複數、be 動詞 |
| 自然 | 動物分類、物質三態、導電、磁力、植物食用部位、酸鹼、人體、自然常識、槓桿 |
| 社會 | 方位、比例尺、年代與世紀、民國與西元、節日與習俗、政府組織、臺灣行政區、社會常識 |
| 資訊 | 二進位、迴圈、變數、條件判斷、硬體與軟體、輸入與輸出、資訊素養 |

題目由 `src/questions/` 內的題庫資料與出題程式產生（固定亂數種子，每次產生的題目都相同）。

## 安裝與啟動

需要 Node.js 18 以上與 PostgreSQL 13 以上。

```bash
# 1. 建立資料庫（以 PostgreSQL 管理者身分執行一次）
psql -U postgres -c "CREATE ROLE quiz LOGIN PASSWORD 'quiz'" -c "CREATE DATABASE quiz OWNER quiz"

# 2. 安裝套件
npm install

# 3. 設定連線（預設為 postgres://quiz:quiz@localhost:5432/quiz）
export DATABASE_URL=postgres://quiz:quiz@localhost:5432/quiz

# 4. 建立資料表並匯入 6000 題（可重複執行，不會重複匯入）
npm run setup

# 5. 啟動網站
npm start        # http://localhost:3000
```

## 設定管理者（老師）

學生都是自行註冊。老師先在網站上註冊一個帳號，再執行：

```bash
npm run make-admin -- 老師的帳號
```

重新整理網頁後，選單會出現「全體報告」。

## 報告

- **我的報告**（每位學生）：登入次數、登入天數、作答次數、正確率、各科進度、最近 14 天作答量、需要加強的主題、最近登入紀錄。
- **全體報告**（管理者）：使用者人數、近 7 天登入人數、最近 30 天每日登入人數、每位學生的登入與各科進度；可依年級篩選、下載 CSV（Excel 可直接開啟）。
- 也可以直接用 SQL 查詢檢視表 `v_student_login_report`、`v_student_subject_progress`。

## 資料表

| 資料表 | 用途 |
| --- | --- |
| `users` | 學生帳號（密碼以 bcrypt 雜湊儲存）、年級、角色 |
| `sessions` | 登入工作階段（HttpOnly Cookie，14 天有效） |
| `login_events` | 每次登入紀錄（時間、IP），供登入統計 |
| `subjects`、`questions` | 科目與題目 |
| `answers` | 每一次作答紀錄 |
| `mastered` | 已答對的題目；在此表中的題目不會再出給該學生 |

## 測試

```bash
npm test   # 需先完成 npm run setup
```

## 部署注意

- 正式上線請使用 HTTPS，並設定 `COOKIE_SECURE=true`。
- 題目內容由程式依資料表產生，老師可以在 `src/questions/` 修改題庫資料後重新執行 `npm run db:seed` 新增題目。
