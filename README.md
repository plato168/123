## 永久網址（建議，約 1 分鐘設定一次）

1. 開啟 [GitHub Pages 設定](https://github.com/plato168/123/settings/pages)
2. **Build and deployment** → Source 選 **Deploy from a branch**
3. Branch 選 **gh-pages**，資料夾選 **/ (root)**
4. 按 **Save**，等待 1～2 分鐘

完成後永久網址為：

**https://plato168.github.io/123/**
